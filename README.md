🌸 Code Blossom: Student Marks Management System
Team 7
A simple and pretty way for teachers to keep track of student marks.

 What this project does
I built Code Blossom to help teachers manage their classrooms better. Instead of using paper, they can type everything into this app.

Main Features
Add and Change Marks: You can add a new student or change their info if you made a mistake.

Automatic Grades: You don't have to guess the grade. The app automatically gives an A, B, C, D, or F.

Pass or Fail: The app shows a green "PASS" or a red "FAIL" badge immediately.

Total Stats: It automatically calculates the class average and shows the highest mark.

Search: You can find a student quickly by typing their name in the search bar.

Safe Data: If you refresh the page, the names and marks stay there.

 Tools I used
HTML: To build the structure of the website.

CSS: To make it look "glassy" and pink.

JavaScript: To make the buttons work and do the math.

 Hard parts (Challenges)
The Math: It was a bit tricky to make the "Average" update every time I added a new student.

The Look: Making the background look blurry (the "glass" style) took some time to get right.

Saving Data: Learning how to make the computer "remember" the list even after closing the tab.

 What I want to add later

More Subjects: Being able to add marks for Math, Science, and English at the same time.
Login Page: A way for teachers to have their own private password.
